SOCIETYCARE - FIELD PROJECT WEB APPLICATION

Exact technologies: HTML5, CSS3, JavaScript, PHP 8+, MySQL.
No framework is required.

Features:
- Resident registration/login
- Admin login
- Resident dashboard
- Complaint submission
- JPG/PNG/WEBP image upload (5 MB max)
- Admin complaint management
- Staff management and assignment
- Complaint status + status history
- Resident feedback after resolution

XAMPP setup:
1. Install XAMPP.
2. Copy this folder into C:\xampp\htdocs\
3. Start Apache and MySQL.
4. Visit http://localhost/societycare/setup.php
5. Delete setup.php after setup.
6. Visit http://localhost/societycare/
7. Admin: admin@society.local / admin123
8. Register a resident account and test a complaint.
